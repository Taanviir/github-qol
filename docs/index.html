Features

Small things, every single review.

Each one fixes something GitHub does a little wrong. Turn any of them off from the toolbar popup.

Annotate screenshots before posting

Press CtrlShiftV in a comment box to add arrows, boxes, text or redactions, then attach. Plain paste works as usual.

Pause and step through GIFs

Freeze a screen recording, go frame by frame with , ., or slow it to 0.25×.

Diffs you can skim

Collapse or expand every file at once. v marks the file as viewed and jumps to the next. Lockfiles and generated files start collapsed.

Load every hidden comment

Long threads hide hundreds of items behind "Load more". One click loads the whole timeline.

Real dates, not "last week"

Anything older than a day shows the actual date and time.

Clickable file paths

src/app.ts:42 in a comment links to that file and line. Only if the file exists.

Blame view that stays put

Switch one file to Blame and the next files you open stay in Blame until you switch back.

Shortcuts GitHub forgot, and a switch for everything

Extra g shortcuts for the pages GitHub's own set skips. Every feature has its own toggle in the popup.

Install

Up and running in a minute.

It isn't on the Chrome Web Store yet, so load it straight from the download.

1

Download and unzip

Grab the latest zip and extract it anywhere.

2

Turn on Developer mode

Open chrome://extensions and flip the switch in the top-right corner.

3

Load unpacked

Click Load unpacked, pick the folder, and refresh any open GitHub tabs.

Make your next review a little smoother.

Free, open on GitHub, and every feature can be switched off.
